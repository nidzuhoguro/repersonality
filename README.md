# Yet another compatibility mod.

Reliquified Artifacts mod by Octo-Studios breaks crawling in the Personality mod by Team Abnormals. This mod fixes it with mixins into RA mod, that determine `Player.setForcedPose()` rights for the mod, so it doesn't set forced pose when it would break crawling state from Personality.
